## Сквозной тест загрузки

Новый `internal/gui/download_e2e_test.go` использует настоящий HTTP API приложения, движок, скрейпер API, HLS, FFmpeg/ffprobe, state-файл и сканирование библиотеки. Каталог и HLS находятся на локальных тестовых серверах; авторизация вымышленная. Медиа генерируются FFmpeg, длительность — 0,4 секунды.

Для **MKV и MP4** проверена вся последовательность:

1. Скачать видео 720p с озвучкой A.
2. Добавить оригинальную английскую дорожку. Число аудиопотоков становится равным двум; новых запросов видеосегментов нет; хеш закодированных видеопакетов совпадает.
3. Повторить тот же выбор. Готовая серия пропускается.
4. Выбрать 360p. Появляется вторая версия файла; старая остаётся на месте; библиотека считает один логический эпизод.
5. Удалить тестовую версию 360p и повторить загрузку. Файл восстанавливается.
6. Сохранить и восстановить очередь из файла.

Существующие тесты дополнительно проверяют точный выбор озвучки, отсутствие захвата комментариев, сохранение субтитров/вложений при добавлении звука, выбор эпизодов, отмену/паузу/повтор, очистку, безопасные пути, HLS-кеш и обновление приложения.

## Зависимости и безопасность

- `npm audit`: **12 уязвимых пакетов до обновления, 0 после**. Обновлены Vite, Vitest, React plugin и транзитивные зависимости; добавлен отсутствовавший `@vitest/coverage-v8`. Исправления Vitest описаны в [официальном advisory](https://github.com/vitest-dev/vitest/security/advisories/GHSA-82fw-gwwq-j7x9).
- Go обновлён с 1.26.3 до **1.26.10**. Обновлены `x/net` до 0.62.0, `x/crypto` до 0.58.0, `x/text` до 0.43.0, `compress` до 1.18.7 и связанные модули. В частности, закрыты исправляемые предупреждения [crypto/x509](https://pkg.go.dev/vuln/GO-2026-6809), [HTTP/2](https://pkg.go.dev/vuln/GO-2026-6617) и [compress/s2](https://pkg.go.dev/vuln/GO-2026-5841).
- Итоговый `govulncheck`: **0 достижимых уязвимостей, 0 в импортируемых пакетах**. Это подтверждено для macOS и отдельно для исходников Windows/Linux с CGO выключенным.
- Осталось одно предупреждение на уровне целого модуля: [GO-2026-5932](https://pkg.go.dev/vuln/GO-2026-5932), устаревший `x/crypto/openpgp`, у которого нет исправленной версии. Приложение этот пакет не импортирует и не вызывает; `x/crypto` нужен для других криптографических примитивов. Это не скрыто и не объявлено «нулём предупреждений вообще».

В CI добавлены frontend-тесты и coverage, проверки зависимостей npm/Go, FFmpeg для сквозных тестов. Для Ubuntu добавлены GTK/ayatana headers, которые нужны существующей нативной tray-сборке. Сам удалённый GitHub Actions в рамках этого локального аудита не запускался.

## Текущая библиотека и ограничения среды

Read-only Доктор обнаружил **9 записей, 8 целых эпизодов и 4 проблемы**: отсутствующий файл «Страха и ненависти» и три временные папки. Автоматический ремонт и очистка не запускались; незавершённые попытки защищены от удаления временных сегментов. У «Разделения» видны восемь файлов и разбивка по озвучкам.

В текущей очереди сохранились три неудачные попытки. У одной FFmpeg сообщил `No space left on device` при сборке MKV; у двух других — таймаут получения API/плейлиста kino.watch. Реальная проверка TLS самого kino.watch также получила EOF, хотя другие внешние серверы проходили. Полная загрузка фильма с внешнего CDN этим аудитом **не подтверждена**. Для неё нужны доступность сервиса и достаточное место под сегменты и итоговый контейнер.

Во время кросс-сборок временно закончилось место и для компилятора. Проверки повторены после очистки только созданного этой задачей кеша и завершились успешно. Пользовательские видео, временные сегменты загрузок и `fresh-instance.png` не удалялись.

На последней проверке файловая система показывает **51 ГиБ свободного места**. Сообщение о нехватке места в очереди относится к предыдущей попытке, а не к текущему замеру свободного пространства.

Итоговая версия запущена на **http://127.0.0.1:8765**. Перед перезапуском проверено отсутствие выполняющихся, ожидающих и приостановленных загрузок. Изменения сохранены локально; публикация релиза в этот аудит не входит.
