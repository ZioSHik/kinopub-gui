# Аудит загрузки и библиотеки — 28 октября 2026

Проверена локальная ветка `codex/redownload-missing-files` поверх `56d690f`.
Ниже перечислены найденные ошибки и исправления. Основные сценарии закреплены регрессионными и интеграционными тестами.

## Загрузка и варианты файлов

| Проблема | Исправление | Проверка |
| --- | --- | --- |
| Готовая серия блокировала выбор другой озвучки или качества | Движок и карточка сравнивают качество, контейнер и выбранные дорожки. Недостающий звук добавляется в прежний файл, другое качество сохраняется отдельной версией | `variants_test.go`, `downloaded.test.ts` |
| Изменение озвучки перезаписывало прежний звук | Загрузка только недостающих аудиодорожек; при сборке сохраняются прежние звук, субтитры, вложения и метаданные | Интеграционный тест с настоящими FFmpeg/ffprobe для MKV и MP4: 1 видео, 2 аудио, 1 субтитр; хеш видеопакетов до и после совпадает, запросов видеосегментов при добавлении звука нет |
| Одноимённые фильмы с разными ID писали в одну папку | Новая папка содержит ID каталога. Старый путь используется только при совпадении ID в состоянии | `regression_collision_test.go` |
| Сломанный плейлист выбранного звука пропускался, загрузка считалась успешной | Ошибка любой выбранной дорожки прерывает попытку и передаётся механизму повторов | `TestSelectedAudioPlaylistFailureIsAnError` |
| После смены качества использовались сегменты прежнего потока | Кеш привязан к содержимому плейлиста, включая URL сегментов и init-сегмент | `regression_resume_test.go`; проверки обычного возобновления и первой сводки прогресса |
| AC3 совпадал с E-AC3 | Сопоставление по наиболее точному имени кодека с нормализацией написания | `regression_audio_test.go` |
| Ошибка записи завершения игнорировалась | Загрузка возвращает ошибку с путём сохранённого файла; успешное завершение не регистрируется | `TestPersistenceFailureIsNotSuccess` |
| При отсутствии нужного разрешения терялся явно выбранный видеокодек | Подбор ближайшего разрешения сохраняет кодек; отсутствие кодека возвращает ошибку | `TestExplicitCodecSurvivesResolutionFallback` |
| Аварийное завершение могло оставить частичный сегмент под именем готового | Сегмент появляется в кеше только после полного скачивания и переименования временного файла | `TestSegmentIsVisibleOnlyAfterFullDownload` |

Состояние хранит прежние версии одного эпизода без увеличения счётчика серий. Библиотека суммирует существующие файлы всех версий, позволяет открыть нужную версию и удаляет их вместе при удалении эпизода. Если последняя версия пропала, но прежняя существует, основным становится доступный файл.

## Дополнительные области аудита

| Область | Ошибка и исправление |
| --- | --- |
| Удаление эпизода | Удаление последнего эпизода больше не удаляет всю папку с посторонними файлами. Пустое состояние исключается из библиотеки; оно сохраняется для согласования с параллельной записью завершений |
| Символьные ссылки | Папки библиотеки и родители удаляемых файлов проверяются после разрешения ссылок. Уход за пределы разрешённого корня отклоняется; все версии проверяются до удаления первого файла |
| Очередь | Относительный путь и ссылка на ту же папку считаются одним назначением, в том числе до создания конечной папки |
| Карточка загрузки | Проверка скачанного ограничивается выбранной выходной папкой. Файл из другой библиотеки не блокирует загрузку в новое место |
| Скрытие завершённых задач | Файл другого назначения не скрывает задачу. Ошибочные задачи остаются видимыми: наличие эпизода само по себе не доказывает наличие нужной озвучки и качества |
| Очистка частичных файлов | Учитываются новые суффиксы качества и прежние пути при добавлении озвучки; очистка и блокировка конфликтов продолжают работать по эпизоду |
| Настройки | Атомарная запись перед заменой активных настроек; ошибка диска сохраняет прежнее состояние. Массив папок копируется на входе и выходе |
| Сохранение очереди | Атомарная запись через уникальный временный файл вместо фиксированного `jobs.json.tmp` |
| Блокировки состояния | Один канонический путь используется для относительных и абсолютных имён, включая ссылки на папки |
| Самообновление | Dev-сборка не заменяет себя релизом. Ошибка определения пути исполняемого файла возвращается вызывающему коду. Установка требует контрольную сумму именно нужного файла; превышение лимита размера возвращает ошибку |
