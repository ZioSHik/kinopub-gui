# Аудит загрузки и библиотеки — 28 октября 2026

Проверена локальная ветка `codex/redownload-missing-files` поверх `56d690f`.
Ниже перечислены найденные ошибки и исправления. Основные сценарии закреплены регрессионными и интеграционными тестами.

## Загрузка и варианты файлов

| Проблема | Исправление | Проверка |
| --- | --- | --- |
| Готовая серия блокировала выбор другой озвучки или качества | Движок и карточка сравнивают качество, контейнер и выбранные дорожки. Недостающий звук добавляется в прежний файл, другое качество сохраняется отдельной версией | `variants_test.go`, `downloaded.test.ts` |
| Изменение озвучки перезаписывало прежний звук | Загрузка только недостающих аудиодорожек; при сборке сохраняются прежние звук, субтитры, вложения и метаданные | Интеграционный тест с настоящими FFmpeg/ffprobe для MKV и MP4: 1 видео, 2 аудио, 1 субтитр; хеш видеопакетов до и после совпадает, запросов видеосегментов при добавлении звука нет |
| Одноимённые фильмы с разными ID писали в одну папку | Новая папка содержит ID каталога. Старый путь используется только при совпадении ID в состоянии | `regression_collision_test.go` |
| Сломанный плейлист выбранного звука пропускался, загрузка считалась успешной | Ошибка любой выбранной дорожки прерывает попытку и передаётся механизму повторов | `TestSelectedAudioPlaylistFailureIsAnError` |
| После смены качества использовались сегменты прежнего потока | Кеш привязан к содержимому плейлиста, включая URL сегментов и init-сегмент | `regression_resume_test.go`; проверки обычного возобновления и первой сводки прогресса |
| AC3 совпадал с E-AC3 | Сопоставление по наиболее точному имени кодека с нормализацией написания | `regression_audio_test.go` |
| Ошибка записи завершения игнорировалась | Загрузка возвращает ошибку с путём сохранённого файла; успешное завершение не регистрируется | `TestPersistenceFailureIsNotSuccess` |
| При отсутствии нужного разрешения терялся явно выбранный видеокодек | Подбор ближайшего разрешения сохраняет кодек; отсутствие кодека возвращает ошибку | `TestExplicitCodecSurvivesResolutionFallback` |
| Аварийное завершение могло оставить частичный сегмент под именем готового | Сегмент появляется в кеше только после полного скачивания и переименования временного файла | `TestSegmentIsVisibleOnlyAfterFullDownload` |

Состояние хранит прежние версии одного эпизода без увеличения счётчика серий. Библиотека суммирует существующие файлы всех версий, позволяет открыть нужную версию и удаляет их вместе при удалении эпизода. Если последняя версия пропала, но прежняя существует, основным становится доступный файл.

| Настройки | Атомарная запись перед заменой активных настроек; ошибка диска сохраняет прежнее состояние. Массив папок копируется на входе и выходе |
| Сохранение очереди | Атомарная запись через уникальный временный файл вместо фиксированного `jobs.json.tmp` |
| Блокировки состояния | Один канонический путь используется для относительных и абсолютных имён, включая ссылки на папки |
| Самообновление | Dev-сборка не заменяет себя релизом. Ошибка определения пути исполняемого файла возвращается вызывающему коду. Установка требует контрольную сумму именно нужного файла; превышение лимита размера возвращает ошибку |

## Дополнение: старые загрузки «Разделения»

После проверки реальной библиотеки исправлено смешение двух счётчиков: число имеющихся файлов и число файлов с выбранными качеством и озвучкой. Теперь общий счётчик показывает 8 из 19 независимо от текущего выбора; соответствие выбранным параметрам отображается отдельно.

Для старых записей без названия озвучки приложение читает теги аудиопотоков из MKV/MP4 через ffprobe, не изменяя видео. Кеш учитывает размер и время изменения файла, а проверка всей библиотеки ограничена общим бюджетом в две секунды. Те же сведения использует движок при проверке уже скачанного.

Фактически найдены серии S01E01–S01E07 с озвучкой «Невафильм», S01E08 — М. Яроцкого. В библиотеке добавлены сводка по озвучкам и подписи у каждого эпизода. Начальный выбор озвучки соответствует наиболее распространённому набору дорожек, вместо объединения разных озвучек из разных серий. Нумерация дорожек больше не мешает распознать уже имеющийся звук при докачке.

Регрессия закреплена тестом самой карточки: восемь файлов, семь старых записей без audio, один файл с записанной озвучкой. Смена выбора не уменьшает общий счётчик. Проверены восстановление тегов настоящего контейнера и обновление кеша после изменения файла. Go-тесты с детектором гонок, go vet и 277 frontend-тестов пройдены. Локальная версия: `v1.1.2-dev-audio`.


## Дополнение: категории озвучек и пустой выбор

Озвучки в карточке сгруппированы по типу перевода. Внутри категории отображаются студия и формат дорожки; исходные идентификаторы выбора и различия AAC/AC3 сохраняются.

При снятии всех озвучек планирование учитывает имеющееся видео в выбранном качестве, поэтому скачанные серии не отмечаются как требующие повторной загрузки. Кнопка показывает «Выберите озвучку», а счётчик соответствия выбранному звуку временно скрывается. На реальной библиотеке «Разделения» проверено: после снятия единственной выбранной озвучки отмечены только 11 отсутствующих серий, восемь скачанных остаются неотмеченными.

279 frontend-тестов и сборка интерфейса пройдены. Локально запущена сборка `v1.1.2-dev-picker`.


## Дополнение: оригинальная дорожка и комментарии

В загрузке «Страха и ненависти в Лас-Вегасе» подтверждён лишний выбор: шаблон «Оригинал» совпадал одновременно с `18. Оригинал (ENG)` и `19. Оригинал. Комментарии (ENG)`.

Теперь положительный выбор обычной озвучки или языка не включает комментарии. Комментарии остаются доступными при отдельном выборе; отсутствие обычного звука не подменяется дорожкой комментариев. Правило действует и для сохранённой конфигурации прежней задачи, и при добавлении звука к уже скачанному видео. Проверка готовых файлов также различает эти виды дорожек.

Карточка отправляет явные правила для каждой выбранной дорожки, даже если выбран весь список API: в HLS могут присутствовать дополнительные дорожки, которых нет в каталоге. Комментарии вынесены в самостоятельную категорию.

Пройдены `go test -race ./...`, `go vet ./...`, 283 frontend-теста и сборка. Регрессионный HLS-тест использует реальные названия обеих дорожек и проверяет отсутствие любых запросов к комментариям при выборе оригинала. Локальная сборка: `v1.1.2-dev-commentary`.
